# Demo credentials (development / Locust / QA only)

Password hashes in the database are Werkzeug `pbkdf2:sha256` (same family as `BackendAuthService`).  
**Do not use in production.** This file is committed on purpose so anyone can sign in after a `down -v`.

Display names and kit labels in seeds are English source strings (Babel msgid style). The portal maps known catalog/seed labels in `apps/BackendWebFlask/i18n.py` and translates them for `es-MX`. Free-text typed by users is not translated.
